# 지성크리닝 웹사이트 2차 회의 수정사항

녹음 전사와 현장 메모를 합쳐 정리한 수정 지시 목록임.
원본은 `지성크리닝 웹사이트 회의.m4a`(1시간 3분, 참석 4명).

납기는 월요일. 관리자 문구 편집 기능은 초안 반영 후 별도 진행.

## 0. 작업 원칙

회의에서 반복해서 나온 지적임. 개별 문구보다 이 원칙이 먼저다.

- **소비자가 볼 때 심플해야 함.** 정보를 늘리지 말고 줄이는 방향
- **요구하지 않은 것을 새로 넣지 말 것.** 1차 회의에서 정하지 않은 항목이 새로 들어와 있었고,
  이번 회의 시간의 상당 부분이 그것을 다시 걷어내는 데 쓰였음
- **하지 않는 일은 쓰지 않음.** 고온 살균·고온 온수는 실제로 쓰지 않으므로 삭제
- **부정 표현을 쓰지 않음.** 「개인 옷은 맡지 않습니다」, 「~는 취급하지 않습니다」 전부 삭제.
  취급하는 것만 계속 노출하면 됨
- **1차 회의 자료(검정 볼펜 표시본) 기준으로 되돌림.** 2안·3안에서 새로 나온 구성은 폐기

원자료는 현재 쓰지 않는 전단지를 바탕으로 만든 것이며, 거기서 뺄 것을 이미 많이 뺀 상태임.

## 1. 용어 통일

| 기존 | 변경 |
| --- | --- |
| 납품 | 배송 |
| 린넨 | 세탁물 (린넨은 소재 이름이므로 부적절) |

| 배달 | 배송 |
| 견적 문의 (버튼) | 전화 문의 |

「고온 살균」, 「고온 온수」는 대체하지 않고 삭제함.

## 2. 상단 탭 구조

- 시설·공정 탭 삭제. 공장 청결 상태를 노출할 수 없어 관련 내용을 통째로 뺌
- 사업개요는 별도 탭으로 두지 않고 회사소개 안에 둠
- 최종 3탭: **회사소개 → 서비스 → 견적 문의**

수정 대상: `website/src/lib/site.ts` 의 `nav`, `website/src/components/site-footer.tsx`.
`/facility` 라우트는 페이지째 제거.

## 3. 홈 화면

### 3-1. 히어로 문구

**「수거부터 배송까지 사업장 세탁물을 대신 관리해드립니다」**

현재 `site.tagline` 의 "린넨", "배달" 표현을 교체해야 함.

### 3-2. 대상 업종

최종 목록은 다음 여섯 가지임.

- 호텔
- 모텔
- 펜션
- 단체시설
- 사우나
- 헬스장

삭제: 기업체, 급식소, 식당, 주방 세탁물. 가운데 배치되어 있던 블록도 함께 뺌.

수정 대상: `website/src/lib/site.ts` 의 `targetIndustries`.

### 3-3. 운영 주기 문구

- 「월 단위로 고정 시간에 운영합니다」 삭제. 거래처가 우리 시간에 맞춰야 하는 것처럼 읽힘
- 「세 가지로 운영합니다」식 가짓수 표현 삭제
- 대체 문구: **「사업장 규모, 품목과 물량에 따라 주기적으로 관리해드립니다」**
- 「원하시는 요일·날짜」 → **「약속된 날짜」**
- 요약 문구: **「약속한 날짜에 수거하고 세탁·살균을 거쳐 배송합니다」**
- 두 개로 나뉘어 있던 탭을 하나로 합침

### 3-4. 진행 단계

제목은 **「첫 상담부터 배송까지」**. 「4단계」라는 단어는 쓰지 않음.
기존 단계별 세부 설명문은 전부 삭제하고 아래로 교체함.

| 단계 | 제목 | 설명 |
| --- | --- | --- |
| 1 | 상담 | 사업장·품목·물량 상담 |
| 2 | 수거 | 약속된 날짜와 시간에 방문 수거 |
| 3 | 세탁 | 전문 설비로 세탁 · 살균 · 건조 |
| 4 | 배송 | 검수 후 배송 |

### 3-5. 삭제할 블록

- **취급 품목 목록 전체.** 취급하지 않는 항목을 일일이 빼다가 목록 자체를 없애기로 함
- **물량과 주기 페이지 전체**
- **가격·단가 안내 전체.** 실제 단가와 맞지 않고, 공개하면 이후 조정이 어려워짐
- **세탁공장 시설 사진과 「공장 자세히 보기」**
- **대량 처리 물량을 강조하는 표현.** 거래처가 자기 세탁물이 뒤섞인다고 느낄 수 있음
- **「정기 세탁이 필요한 곳에 맞춤…」류 블록**
- **「확인 후 연락드립니다」**

수정 대상: `website/src/components/price-table.tsx`, `website/src/lib/pricing.ts`, `/facility` 페이지.

### 3-6. CTA

- **「바로 문의하기」** 로 통일
- 「24시간 상담」 표현 금지. 실제로 새벽에 받을 수 없으므로 쓰지 않음
- 견적 문의 버튼은 스크롤을 따라다니게 함(플로팅). 아래로 내려간 뒤 다시 찾아 올라가는 수고를 없앰
- 어느 경로로 눌러도 문의 페이지 또는 전화로 연결

## 4. 전화 · 문자

- 전화번호 교체 필요. 현재 코드 값은 054-621-5002
- 버튼 이름은 「전화 문의」
- 모바일: 누르면 전화 걸기
- 웹(PC): 번호만 표시하고 동작하지 않게 함
- 문자 보내기 기능 추가. 누르면 문의 내용이 자동 작성되고 번호만 채우면 발송되는 형태.
  우선순위는 후순위이며 초안 반영 후 진행

## 5. 회사소개

3탭 중 첫 번째. 시설·공정 관련 서술은 통째로 삭제하고, 「제조법인」 표현도 쓰지 않음.

### 5-1. 상단

| 구분 | 문구 |
| --- | --- |
| 큰 글씨 | (주)지성이엔지 지성크리닝 |
| 작은 글씨 | 우수조달업체 (주)지성이엔지에서 운영하는 세탁 사업 부문입니다 |

### 5-2. 사업 개요

| 구분 | 문구 |
| --- | --- |
| 큰 글씨 | 사업장 세탁물을 관리해드리겠습니다 |
| 작은 글씨 | 「안전한 시공 및 점검으로 신뢰받는 기업」 (주)지성이엔지 파트너 지성크리닝입니다 |

「안정한」이 아니라 **「안전한」**. 본사 홈페이지는 「안정한」을 쓰지만 직관성이 떨어져 이 사이트에서는 안전으로 통일함.

### 5-3. 그 밖에

- 장애인 표준사업장 문구는 유지하되 회사소개 페이지에 배치. 홈 중간에서는 뺌
- 세부정보 주소 표기는 유지
- 소재지 지역명이 **강동면**으로 바뀜. 현재 코드는 천북면으로 되어 있어 확인 후 수정 필요

## 6. 견적 문의 폼

현재 필드를 아래로 교체함.

| 필드 | 필수 여부 | 비고 |
| --- | --- | --- |
| 업체명 | 필수 | 유지 |
| 성함 | 필수 | 「담당자」에서 명칭 변경 |
| 연락처 | 필수 | 유지 |
| 주소 | 필수 | 「사업장 지역」에서 명칭 변경 |
| 업종 | 선택 | 아래 항목으로 축소 |
| 이메일 | 선택 | 유지 |
| 문의 내용 | 선택 | 유지 |
| 개인정보 이용 동의 | 필수 | 반드시 포함 |

- 삭제: 주당 예상 물량, 희망 수거 주기, 세탁 품목 선택
- 업종 항목: 숙박시설 / 단체시설 / 사우나 / 헬스장 / 기타.
  기업체 · 급식소 · 식당은 뺌
- 필수·선택을 빨간 별표만으로 표시하지 말고 **필드 옆에 「필수」 「선택」 글자로 표기**.
  연세 있는 담당자가 직관적으로 알아볼 수 있어야 함

수정 대상: `website/src/components/quote-form.tsx`, `website/src/lib/schema.ts`.

## 7. 신규 요청

### 7-1. 후기 섹션

- 문의 영역 아래에 후기 카드를 옆으로 흐르는 형태로 추가
- 인스타그램 광고에서 보이는 카드 형식 참고
- 문구는 지성크리닝 측에서 작성해 전달.
  예시로 「친절한 상담」, 「빠른 배송」, 「깨끗한 세탁물」 등이 거론됨

### 7-2. SNS

- 인스타그램 · 블로그 링크 자리를 만들어 둠. 계정은 추후 개설
- 사진 소재는 배달 차량 사진 정도로 시작

### 7-3. 관리자 문구 편집

- 관리자 페이지에서 문구를 직접 수정할 수 있게 함
- **즉시 반영하지 않음.** 수정안을 1안 · 2안 · 3안 형태로 저장해두고 회의를 거쳐 반영
- 게시판 형태로 안을 쌓아두는 구조
- 초안 수정 완료 후 별도 작업

기존 `/admin/inquiries` 외에 문구 편집 화면이 추가로 필요함.

## 8. 디자인

- 현재 디자인 유지. 심플하고 깨끗하다는 평가
- 색상 유지. 회사 로고 색상과 같은 계열이라 그대로 감
- 로고가 나오면 전달받아 교체

## 9. 확인이 필요한 것

- **소재지 지역명.** 강동면으로 바뀌는지, 현재 코드의 천북면이 맞는지
- **전화번호.** 교체한다고만 하고 최종 번호는 확정되지 않음
- **장애인 표준사업장 인증 보유 여부와 증빙 서류.** 취득 진행 여부를 경영지원부에 확인해야 함
- **인스타그램 · 블로그 계정 존재 여부**
- **후기 문구 원고**

## 10. 기존 문서와의 관계

이 문서는 홍보 웹사이트(`website/`)에 대한 것임. 주문관리 시스템(`Document/결정사항.md`)과는 별개다.
다만 다음은 서로 맞춰야 함.

- **업종 분류.** 이 회의에서 숙박시설 · 단체시설 · 사우나 · 헬스장 · 기타로 좁혀짐.
  결정사항 문서의 예시(호텔·모텔 침구, 식당 앞치마, 헬스장 수건)와 범위가 어긋나므로
  정식 개발 착수 전에 맞춰야 함
- **용어.** 결정사항 문서는 도매 기준으로 「납품」을 쓰지만, 대외 웹사이트는 「배송」으로 통일함.
  내부 시스템 용어는 별개로 둠
- **가격 비공개 방침.** 결정사항 2-5(거래처별 계약단가)와 같은 맥락임
